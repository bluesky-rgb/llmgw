# 行为准则 / Code of Conduct

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)（[其他语言的译本](https://www.contributor-covenant.org/translations)）。正文以官方页面为准，这里只写本项目怎样执行。

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The official text is authoritative; this file only describes how it is enforced here.

## 适用范围 / Scope

本仓库的 Issues、Pull Requests、Discussions、代码评审，以及以项目名义进行的其他交流。

All project spaces: issues, pull requests, discussions, code review, and any communication on behalf of the project.

## 举报 / Reporting

请**私下**举报，不要在公开的 Issue 或讨论中举报：

1. 打开仓库的 [Security → Report a vulnerability](https://github.com/bluesky-rgb/llmgw/security/advisories/new)（这是 GitHub 的私密报告通道，只有维护者能看到）
2. 标题以 **`[行为准则]`** 或 **`[Code of Conduct]`** 开头，写明发生了什么、在哪里（链接）、涉及谁

Report privately through [Security → Report a vulnerability](https://github.com/bluesky-rgb/llmgw/security/advisories/new) (GitHub's private reporting channel, visible only to maintainers) and start the title with **`[Code of Conduct]`**.

目前项目只有一位维护者；如果举报涉及维护者本人，可以直接向 [GitHub 举报](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)。

维护者会在 7 天内回复，并对举报人的身份保密。处理方式按 Contributor Covenant 2.1 的“执行指南”（更正、警告、暂时禁止、永久禁止）。

The project currently has a single maintainer; reports about the maintainer can go to [GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) directly.

Maintainers will respond within 7 days and keep the reporter's identity confidential. Consequences follow the Enforcement Guidelines of Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban).
