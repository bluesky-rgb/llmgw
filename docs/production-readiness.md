# 生产就绪检查清单

> 本文列出 llmgw 作为生产系统上线前需要满足的条件，按优先级排进里程碑。设计层面的改动已同步到 [design.md](design.md)；每完成一项，把状态改为 ✅。

**优先级：**
- **P0**：不解决就不能上线
- **P1**：v1.0 应该具备
- **P2**：可以在 v1.x 完成

## 0. 待决定：部署位置

部署位置决定了网络连通性、延迟和合规风险。在作者确定之前，v1.0 按“两种都支持”来设计（出站代理是 P0）。

| | 部署在国内 | 部署在海外 |
|---|---|---|
| 访问 MiniMax（国内站）、MiMo | 延迟低、稳定 | 跨境访问，延迟和稳定性需要实测 |
| 访问 OpenAI | **需要出站代理**；还需要确认 OpenAI 是否支持在该地区使用 | 直连 |
| 合规 | 用户数据发往境外厂商时，涉及数据出境 | 国内用户的数据本身就出境了 |
| 建议 | 国内用户为主时选择 | 海外用户为主，或以 GPT 为主力模型时选择 |

**决定：** ☐ 国内　☐ 海外　☐ 两地各部署一套
